# 말과 소리

구름이는 차가 P단에 있을 때만 말합니다. 달리는 동안에는 출발 차임 한 번과 살살 멈출 때의 깃털 소리만 냅니다. 목소리는 차 안의 음성 엔진이 만들고, 문장은 앱에 정해 둔 틀에서 고릅니다.

## 말은 P단에서만

- 목소리를 내기 직전에 차가 달리는 중인지 다시 봅니다. 달리는 중이고 P단이 아니면 말하지 않습니다.
- 음성 엔진은 처음 준비하는 데 1초 남짓 걸립니다. 그사이 출발해도 첫소리 직전에 한 번 더 보고 멈춥니다.
- 출발하면 읽던 말을 바로 끊고, 미뤄 둔 말도 버립니다.
- 말하지 못해도 화면과 알림의 글은 그대로 남습니다.

P단일 때 하는 말은 아래와 같습니다. 예시의 "도토리" 자리에는 아기 정령 이름이 들어갑니다.

| 때 | 구름이 말 |
|---|---|
| 뒷자리에 탄 뒤 6초가 지나도 안전벨트가 풀려 있을 때 | "친구야, 벨트 찰칵해 줄래?" |
| 같은 때, 그 자리에 아기 정령이 있으면 | "도토리가 깨어나게 벨트 찰칵해 줄래?" |
| 안전벨트를 매서 아기 정령이 깨어날 때 | "찰칵! 도토리가 일어났어." |
| 탄 사람이 모두 안전벨트를 매고 아기가 둘 이상 깨어날 때 | "다 모였다! 오늘도 같이 가자." |
| 아기 정령이 없는 차에서 뒷자리 안전벨트를 맬 때 | "찰칵! 고마워. 오늘도 같이 가자." |
| 1시간 이상 내렸다가 다시 탈 때 | "왔구나! 도토리가 반가워해." |
| 아기 정령을 처음 들일 때 | "반가워! 도토리가 우리 차에 왔어." |

- 여러 자리가 잇달아 안전벨트를 매면 1.5초 동안 모아 한 문장으로 말합니다.
- 같은 자리에는 1분 안에 다시 인사하지 않습니다. 잠깐 내렸다 다시 탄 자리는 조용히 맞습니다.
- 회상 그림책을 펼치면 쪽마다 문장을 읽습니다.
- 집 화면의 말풍선은 글로만 보입니다. 날씨나 정비 이야기도 말풍선으로 전합니다.

## 도착 일기를 읽는 때

P단에 3초 두면 도착입니다. 8초 이상 달렸을 때만 일기를 씁니다.

- 앱이 화면에 보이면 도착 카드가 열리고, 구름이가 일기를 읽습니다. 읽는 동안 구름이 입이 움직이고, 다 읽을 때까지 카드가 닫히지 않습니다.
- 다른 앱이 앞에 있으면 카드가 막힙니다. 2초 뒤에도 카드가 없으면 소리로만 읽고, 소리 없는 알림 "도착! 구름이의 일기"를 남깁니다.
- 알림을 눌러 연 카드는 다시 읽지 않습니다. 막혔던 카드가 나중에 떠도 이미 읽은 일기면 읽지 않습니다.
- 일기를 읽는 동안 다른 말은 미뤘다가, 일기가 끝나면 마지막 말 하나만 합니다.
- 40초가 지나면 미룬 말을 하고, 그사이 출발하면 버립니다.

뒷자리 안전벨트를 맨 채 도착하면 아이가 잠들어 있을 수 있습니다.

- 일기를 바로 읽지 않습니다. 10초 안에 뒷자리 안전벨트가 모두 풀리면 그때 읽고, 아니면 읽지 않습니다.
- 밤에는 풀려도 읽지 않습니다. 부모가 잠든 아이를 안아 내리며 안전벨트를 풀기 때문입니다.
- 도착 화면의 효과음도 끕니다. 낮에 안전벨트가 풀리면 다시 켭니다. 카드와 알림의 글은 그대로 남습니다.
- 이 도착 뒤에 연 회상 그림책도 음악과 낭독 없이 넘어갑니다.

## 달리는 동안의 소리

| 때 | 소리 | 규칙 |
|---|---|---|
| 출발 | 차임 1.5초 | 출발할 때마다 한 번. R이나 N으로 빼도 울립니다 |
| 살살 멈추기 | 깃털 소리 0.16초 | 한 번 다녀올 때 3번까지, 1분 이상 띄웁니다. 뒷자리 안전벨트가 채워져 있으면 내지 않습니다 |
| 급제동, 놓친 깜빡이 | 없음 | 달리는 동안에는 나무라지 않습니다 |

주행 중에는 말하지 않고, 새 알림도 띄우지 않습니다.

## 통화 중이거나 다른 소리가 날 때

말하기 직전에 소리 낼 차례(오디오 포커스)를 잠깐 받습니다. 음악은 그동안 작아졌다가 다 읽으면 돌아옵니다.

- 통화 중이면 말하지 않습니다. 차가 소리 낼 차례를 주지 않을 때도 말하지 않습니다.
- 에뮬레이터에서는 음성 명령 중에도 차례를 받아 일기를 읽었습니다. 이대로 둘지는 아직 정하지 않았습니다.
- 읽는 중에 전화벨처럼 다른 소리가 포커스를 가져가면 낭독을 멈춥니다.
- 끝났다는 알림이 오지 않아도 포커스를 오래 쥐지 않습니다. 글자당 0.25초에 3초를 더한 만큼, 길어도 40초 뒤에 돌려줍니다.
- 차임과 깃털 소리도 같은 규칙을 따릅니다. 건너뛴 깃털 소리는 3번에 세지 않습니다.

## 일기 문장 규칙

일기는 보통 두 줄입니다. 목소리는 줄을 이어 한 문단으로 읽습니다.

첫 줄은 함께 달린 시간입니다. 거리는 말하지 않습니다. 분은 반올림하되 1분보다 적게 말하지 않고, 한 시간부터는 30분 단위로 말합니다.

- "오늘은 25분쯤 같이 달렸어."
- "오늘은 1시간 반쯤 같이 달렸어."

둘째 줄은 한 가지만 고릅니다. 위에서부터 보고, 맞는 것이 있으면 아래는 보지 않습니다.

| 이런 날이면 | 둘째 줄 |
|---|---|
| 경고등이 켜져 있음(연료와 워셔액 빼고) | "발이 아파. 타이어 공기압을 봐 줘." |
| 혼자 5분 넘게 달렸고, 아기가 맡긴 말이 있음 | "도토리가 전해 달래. 많이 사랑해." |
| 안전벨트로 깨어난 아기 정령과 함께 탐 | "도토리가 벨트를 먼저 챙겨 줬어, 고마워." |
| 아기 정령 없이 뒷자리 안전벨트를 채움 | "친구가 벨트를 먼저 챙겨 줬어, 고마워." |
| 아기 정령 없이 조수석에 누군가 안전벨트를 매고 탐 | "오늘은 같이 타서 든든했어." |
| 오는 길에 쉬어 감 | "쉬어 가 준 덕분에 바깥 공기를 마셨어, 고마워." |
| 살살 멈추기가 깜빡이보다 많거나 같음 | "부드럽게 멈춘 게 3번! 깃털을 그만큼 모았어." |
| 깜빡이가 더 많음 | "깜빡이를 미리 켜 줘서 깃털을 모았어." |
| 칭찬할 운전 없이 급제동 | "아까 조금 출렁였어, 다음엔 천천히 멈춰 줘." |
| 칭찬할 운전 없이 놓친 깜빡이 | "깜빡이를 먼저 켜 주면 깃털을 더 모을 수 있어." |
| 그 밖에, 선물 열일곱 가지를 다 받은 뒤 | "벌써 200일을 함께했어, 고마워." 날수는 함께한 날입니다 |
| 그 밖에 깃털이 늘었음 | "오늘처럼만 달리면 금방 자랄 것 같아." |
| 깃털이 늘지 않았음 | "깃털은 못 모았지만, 같이 달린 것만으로도 좋았어." |

셋째 줄은 아기 정령과 함께 탄 도착이 3번째, 10번째, 30번째일 때만 붙습니다. 아기가 새 일을 배운 날입니다.

- "도토리가 자기 몸짓을 보여 주기 시작했어."
- "도토리가 내 일을 거들기 시작했어."
- "도토리가 나랑 같이 놀기 시작했어."

함께한 날이 백일 같은 기념일이 되면 도착 카드가 한 줄을 더 읽습니다. "오늘로 백일이야."

말투는 이렇게 맞춥니다.

- 반말로 짧게 말하고, 구름이는 자기를 "나"라고 합니다.
- 한 문장에 숫자는 하나, 느낌표도 하나까지입니다. 이모지는 쓰지 않습니다. 목소리가 그대로 읽기 때문입니다.
- 한두 번은 숫자 없이 말하고 세 번부터 셉니다. "1번이나"처럼 뜻이 어긋나지 않게 합니다.
- 급제동과 놓친 깜빡이는 횟수를 말하지 않습니다. 부탁은 칭찬할 운전이 없는 날에만 합니다.
- 대사는 아이에게 하는 짧은 말이라 "벨트 찰칵"처럼 "벨트"라고 합니다. 설명 글에서는 "안전벨트"라고 씁니다.
- 소리 내어 읽을 때만 숫자를 고유어로 바꿉니다. 화면의 "3번"과 "1시간 반"은 "세 번", "한 시간 반"으로 읽습니다. 분, 일, km처럼 한자어로 읽는 단위는 그대로 둡니다.

## 기기 안 음성

- 목소리는 Pleos TextToSpeech SDK 3.3.1의 기기 안(ON_DEVICE) 모드로 만듭니다. 문장을 서버로 보내지 않고, 인터넷이 없어도 읽습니다.
- Pleos 기본 목소리를 씁니다. 구름이만의 목소리는 따로 만들지 않았습니다.
- 음성 엔진은 처음 말할 때 준비합니다. 준비가 실패하면 그 엔진을 버리고 글로만 보여 줍니다. 다음 말에서 다시 준비합니다.
- 음성 권한(`TTS_SERVICE`)이 없어도 앱은 멈추지 않습니다. 글로만 보여 줍니다.

아기 이름을 불러 함께 태우는 이름 부르기는 검증 빌드에만 있습니다. 기기 안 음성 인식으로 듣고, 들은 소리를 자모로 풀어 가장 가까운 이름을 고릅니다. 부르면 구름이가 목소리로 대답을 전합니다.

무엇을 잘한 일로 세는지는 [차량 신호와 판단 기준](signals.md), 앱 구조는 [구조](design.md)에 있습니다.
